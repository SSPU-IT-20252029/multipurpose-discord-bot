# Planned Features

The following features are listed in the project's `TODO.md` but are **not yet implemented** in the current Go codebase. They are aspirational goals for the bot:

## Music Player

- In-discord music playback
- Web dashboard as a custom alternative to Fibra

## Temporary Voice Channels

- Dynamic temporary voice channels
- Full user management (rename, limit, kick, etc.)
- Auto-cleanup when all members leave

## Moderation Suite

Full Sapphire feature suite equivalent:
- Action logging
- Role connections
- Join/leave/boost alerts
- Moderation commands (warn, mute, kick, ban)
- Auto-moderation
- Appeal system

## Ticket System

Full ticket system equivalent to Tickety:
- User creates ticket via button/command
- Private channel created with support team
- Close/reopen/transcript functionality

## Server Statistics

Comprehensive server statistics and analytics (Statbot equivalent):
- Member growth graphs
- Message activity
- Voice activity
- Engagement metrics

## Code Compiler

- In-discord code block execution
- Compilation for multiple languages
- Output displayed directly in chat

## Free Game Deals

- Free games and deal notifications
- Sources: Steam, Epic Games Store, etc.
- Automatic posting to configured channel
